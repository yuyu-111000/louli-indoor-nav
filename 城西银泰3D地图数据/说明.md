# 城西银泰 3D 地图数据导出

导出日期：2026-10-11。来源：当前楼里产品中的城西银泰空间地图。

## 文件
- kiosk-map.json：完整地图数据，原字段和数值保留。
- floors/：B1、1F、2F、3F、4F 分层 JSON。
- shops.csv：店名、楼层、相对坐标、区域关联与核对状态。
- zones.csv：轮廓、颜色、中心、照片像素面积及关联店名。
- vertices.csv：每个轮廓顶点；原像素坐标和 0–1 归一化坐标。
- floor-summary.csv：分层数量汇总。
- render-settings.json：颜色、铺位视觉厚度、楼层倾斜和间隔参数。
- svg/：各层独立矢量图，用当前 UI 的可见侧面规则展示轻微立体效果。
- photos/：五层原始导览照片和立体参考照片。
- renderer/：当前展示用的两个 JavaScript 文件和样式，供接入参考。

## 坐标与使用
坐标原点在照片左上角，x 向右，y 向下；参考画布为 1706 × 1279。
shape 是轮廓顶点，最后一个点与第一个点相连；center 是轮廓区域中心。
shops 的 x/y 是文字标注位置，zoneId 关联颜色区域。
区域可能关联多个店名，也可能没有可读店名；不要把一个色块直接视为一间独立店铺。
confidence=clear 表示照片文字可辨，review 表示仍需核对；不代表实地验证。
照片像素面积不是建筑面积，楼层之间的照片坐标也未经测量配准。
完整 JSON 保留原网页 photo 路径；独立使用时请改为本数据包的 photos/ 路径。

## 立体模型性质
现有展示采用照片轮廓加视觉厚度的 2.5D SVG 和 CSS 倾斜叠层。
16/25 是绘图坐标偏移，不是实测房间高度；楼层板边界也是 UI 示意。
本包没有新增虚构的楼高、店门、通路、真实路线或定位坐标。
如需真实三维模型或导航图，需要补充尺度、楼高、出入口和通行连接。
