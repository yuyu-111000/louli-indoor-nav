# 楼里展示包实施计划

Goal: 完成可对外演示的产品体验，并保留数据、地图与队列接入边界。

Architecture: 前端为静态 HTML/CSS/JS，仿真分成几何、路径、定位、场景状态、渲染与交互文件。Python 本地后端提供版本化 JSON API，SQLite 保存场馆包与队列。种子包与用户包遵循同一契约。

## 产品边界

当前为演示系统。接口承载模拟或用户提供数据；没有真实 HIS、定位 SDK 或西溪银泰地图授权。地图 v1 支持米制矩形房间、门点和走廊，单层路线。生产认证、实时设备遥测、多人定位和公网账户权限不在本轮范围。
