# 附近场馆接入与展示选择

2026-10-08更新。默认选择杭州城西银泰城：提供资料中的室外锚点距紫金港约1.55公里（直线），西溪印象城约7.53公里。这只帮助选择洽谈对象，不能用来估计出行时间。

## 本轮接入

- 六个场馆的地址、WGS84坐标、原始锚点类型、OpenStreetMap地点链接及直线距离；校园作为参考起点，列在目录说明中。
- 两家商场的独立示意包，可在“附近场馆”切换。默认城西银泰展示任务清单、多点路线、模拟叫号返回提醒和信标概念。
- 后端目录API及可持久化的location/indoorStatus字段，未来导入包不必在前端写死场馆信息。

## 数据真实性

用户提供文件副本保存在docs/sources：zjg_venue_map_research.md及zjg_venue_nav_data.json。附件截图是场馆名称列表；JSON是室外POI和标注demo_simulated的室内模板，未包含任何实际商场楼层平面。

两家商场的室内矩形布局、模拟入口、商铺和队列由本项目整理为演示数据；不是商场现状。它们未采用真实楼层尺度，不可将导航米数当成实测。医院未伪造室内图；浙大院区标注校园锚点，城东/滨江标注入口或公交站参考点。

地图数据来源归属：© OpenStreetMap contributors，https://www.openstreetmap.org/copyright 。原始资料来自用户，未重新现场核验。原始amap_url未用于产品，因为资料为WGS84，不能直接当作高德GCJ-02坐标。

## 对合作方怎么展示

“我们已整理附近场馆的公开地点资料。这一版用室内示意说明体验；如果贵方提供一层的平面图、入口与服务点清单，我们可以替换示意内容，讨论一个小范围试点。”

下一轮需要一层平面图及使用许可、尺度、门点、可通行走廊、真实POI清单；叫号数据可先用假包演示。现有JSON接口可接收整理后的单层几何，尚不支持直接上传CAD/PDF/图片自动识图。

## 验证

后端20项、前端10项测试通过，含六场馆目录API、距离计算、非法地点数据拒绝、location导入保存、两个商场所有示意门点寻路。浏览器核对默认城西银泰、目录六项、西溪切换、四个展示章节、390px手机宽度无横向溢出。展示截图及四章节GIF在交付包media目录。
