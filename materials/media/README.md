`yintai-public-floor.gif` 是本轮对外展示的首选材料：城西银泰 F1 公开截图、商户点选、F2 资料覆盖提示，以及下一章的仿真路线。静态截图对应 `yintai-public-floor.png`、`yintai-public-selected.png`、`yintai-f2-coverage.png` 和 `yintai-public-route.png`。
